# Pet Valley Clinic — تطبيق Next.js

هذا المجلد يحتوي التطبيق الكامل المرفق والمعدّل: الموقع، المتجر، السلة، الحجوزات ولوحة الإدارة.

## تشغيل محلي

1. ثبّت Node.js 22 أو أحدث.
2. من هذا المجلد نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local` وضع رابط قاعدة PostgreSQL وكلمة مرور إدارة قوية.
4. شغّل `npm run dev`.

## النشر

هذا التطبيق ديناميكي ويتطلب بيئة Node.js وقاعدة PostgreSQL؛ **GitHub Pages لا يشغّل واجهات API أو قاعدة البيانات**. يمكن استخدام المستودع لتخزين الشفرة، ونشر التطبيق الكامل على منصة تدعم Next.js وتهيئة المتغيرات السرية هناك. لا ترفع ملف `.env.local` أو كلمات المرور إلى GitHub.

## الألوان

تستخدم أزرار الإجراءات الأساسية لونًا عسليًا متناسقًا مع أخضر وبيج الهوية. متغيرات اللون موجودة في `src/app/globals.css`.
