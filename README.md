# Pet Valley Clinic

الموقع الثابت في جذر المستودع مهيأ للنشر على **GitHub Pages**. مصدر تطبيق Next.js الكامل موجود في [`next-app/`](./next-app)، ويشمل المتجر والحجوزات ولوحة الإدارة.

> تنبيه: GitHub Pages يستضيف الملفات الثابتة فقط. نسخة Next.js تحتاج خادم Node.js وقاعدة PostgreSQL لتشغيل واجهات API والحجوزات ولوحة الإدارة. تعليمات التشغيل في [`next-app/README.md`](./next-app/README.md).

## المتجر

تصميم المتجر مستوحى من مرجع المستخدم، مع بطاقات تصنيفات بصور وأزرار شراء بلون عسلي ينسجم مع الأخضر والبيج.

## GitHub Pages

سير عمل النشر موجود في `.github/workflows/pages.yml` ويعمل عند الدفع إلى فرع `main` بعد تفعيل Pages للمستودع باستخدام النشر عبر GitHub Actions.
